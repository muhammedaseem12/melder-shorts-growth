# Melder clip worker\n\nPrivate FastAPI + FFmpeg worker for direct video-file URLs. It intentionally does not download YouTube pages or bypass platform restrictions. Current baseline extracts evenly spaced excerpts; AI highlight detection, speech transcription and caption generation are not included yet.\n\nSet `CLIPPER_WORKER_SECRET` to a long random secret. The Vercel frontend/API must also have `CLIPPER_WORKER_URL` and the same `CLIPPER_WORKER_SECRET`.\n
